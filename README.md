# 交易中控台（dsh-trading-cockpit）

DSH 双端插件：在左侧栏加入「中控台」图标，点开后是中央大页面。它把《执行手册》、当日交易与当日 K 线放在同一张模块板上，并提供给 agent 调用的交易工具。

## 安装

在 DSH 里打开 **设置 → 插件 → 添加本地插件**，选择本目录：

```text
<TradeSystem 工作区>/plugins/dsh-trading-cockpit
```

或让 agent 调用 `plugin_manager` 的 `install_bundle`，target 填本目录的绝对路径。安装后刷新页面，左侧栏出现「中控台」图标。

## 模块板

- **KPI 卡**：交易日、时段、距收盘倒计时、当日已实现、持仓浮动、日亏剩余。
- **01 失误清单**：累计历史与今天的错误码，按次数排序；齿轮打开错误库。
- **02 风险闸门**：时段、日亏、连亏、连赢、持仓/挂单五项检查，先给结论再列明细。
- **03 盘中走势**：当日 3 分钟 K 线（可切 15 分钟），叠加开平仓圆点、止损/目标/入场虚线、EMA20、ATR14；可切涨绿/涨红两套配色。K 线只画当前品种。
- **04 交易记录**：筛选、分页、搜索；「＋ 添加交易」打开弹窗。
- **05 执行手册**：搜索 + 章节目录 + 原文行号；点结果直接看整节。
- **06 决策**：二元决策图，按 15m 状态、方向、3m 对齐、回踩/边缘、信号 K、止损、目标 R 逐项判断，给出「可做多 / 可做空 / 等待 / 不做」。

### 配色与主题

面板内嵌样张的浅色/深色调色板（背景、面板、边框、文字、强调、涨跌、K 线）；`detectScheme()` 跟随 DSH 当前明暗自动切换，宿主 token 只在无法判断时兜底。「涨绿 / 涨红」只交换涨跌色，不改变通过/拦截等状态色。

## 添加交易

弹窗里可以改合约（自动切换乘数）、方向、入场/止损/目标、手数、入场/离场时间、15m 状态、形态、错误码和备注；也支持拖拽/选择/粘贴账户截图。打开时焦点落在第一个表单控件，Tab 在弹窗内循环，Esc 关闭。

保存后弹窗关闭，新行高亮。结构错误会拦截；止损过大、风险超 600、禁开仓时段、已有多笔等只告警，不拦截保存。

## 截图记录交易

1. 在聊天里发账户成交截图，说明要记的交易。
2. agent 用 `trading_trade_draft` 生成草稿（不会写入正式记录）。
3. 回到「中控台 → 04 交易记录」，在「截图草稿」里直接改字段；账户截图一般没有止损，补上止损后「确认入账」才亮起。
4. 识别不准的字段可以就地改，或丢弃草稿后手工录入。

## 交易时段与刷新

K 线不实时轮询：打开面板时按缓存补拉；每个交易时段结束（10:15 / 11:30 / 15:00 / 23:00）后的第一次打开会重新拉取；也可以点「刷新」。

交易日按期货夜盘归属：21:00–23:00 的夜盘归下一个工作日，K 线窗口是「前一交易日 21:00 → 当日 15:00」。

## 数据与同步

- 交易记录：`notes/TradeLog/cockpit/YYYY-MM-DD.json`（原子写）。
- 截图草稿：`notes/TradeLog/cockpit/drafts.json`。
- 形态/错误字典：`notes/TradeLog/cockpit/dict.json`。
- 交易截图：`notes/TradeLog/cockpit/shots/<uuid>.<ext>`，交易里用 `extended.shot` 关联。
- 不修改现有的 `notes/TradeLog/交易记录.csv` / `交易明细.md`。

插件目录与交易数据都在 `TradeSystem` 工作区内，整个目录用 git / Syncthing / 网盘同步到另一台电脑即可；插件本身不写死本机绝对路径，安装到另一台电脑后在 DSH 里重新选择本目录安装。

## Agent 工具

| 工具 | 用途 |
| --- | --- |
| `trading_rule_search` | 搜索执行手册，返回章节/行号/片段 |
| `trading_manual_section` | 读取某一节完整原文 |
| `trading_trade_draft` | 把截图识别结果存为草稿 |
| `trading_trade_save` | 把确认后的交易写入当日记录 |
| `trading_trade_list` | 列出某交易日记录与汇总 |
| `trading_kline` | 读取当日 K 线摘要（ATR14 / EMA20 / 最近几根） |
| `trading_day_status` | 当前时段、盈亏、连亏连赢、风控闸门 |

`trading_trade_draft` / `trading_trade_save` 的 `errors` 参数用逗号分隔错误码（如 `E1,E5`），会写入 `extended.errors`，用于失误清单和 `/stats` 统计。

## 数据源

新浪期货分钟线（`stock2.finance.sina.com.cn`），Host 代理抓取并缓存；接口失败时显示错误，手工录入不受影响。

看盘优先用主力连续（如 `PP0`）。截图里的具体合约（如 `PP2601`）可能已换月，新浪没有当日分钟线，选中后会显示空图；交易记录仍可按具体合约保存。
