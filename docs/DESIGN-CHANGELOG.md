# 交易中控台 · 改版记录

从「通用后台观感」到现在的模块板，一共走了 12 轮。这份文件是改版的完整记录，样式细节见 `mock/README.md`，静态样张见 `mock/index.html`。

日期：2026-11-28

---

## 0. 起点与结论

- 起点：`client.js` 的 `tc-*` 是一套通用后台样式——12px 圆角卡片、药丸 badge、8px 圆角按钮、顶部 6 个 tab + 页面切换。
- 参考：歸藏设计的 DSH 插件（瑞士/杂志排版：0 圆角、1px 细线、等宽小标签、单一强调色、编号章节）。
- 结论：**不引入 shadcn / Tailwind / Radix**。shadcn 是 copy-paste 组件，依赖 Tailwind v4 + 项目根 + tsconfig 别名，和「单文件 client bundle + 宿主 token」的约束冲突；只借它的设计语言，用宿主 `--dsw-alias-*` 自己写。

---

## 1. 设计语言（最终态）

| 项 | 取值 |
| --- | --- |
| 圆角 | 全部 0（卡片、按钮、输入框、tag、弹窗） |
| 分隔 | 1px 细线，`--dsw-alias-border-l1 / l2`，层次靠线不靠阴影 |
| 字体 | 正文 system-ui；数字/标签/时间用等宽，`.06–.14em` 字距 |
| 强调色 | 只用一个 `--dsw-alias-brand-primary`（蓝），其余是墨色与中性灰 |
| 涨跌色 | 两套可切：绿涨红跌（国际）/ 红涨绿跌（国内）；状态色（通过绿、拦截红）**不跟着翻** |
| 字号 | 区块标题 14/600、KPI 25/300、正文 13、标签 10–11 等宽 |
| 动效 | `rise`（模块入场，按索引错峰 45ms）、`swap`（翻页/筛选换行）、`newrow`（新行高亮 1.8s）、`dlgPop`；`prefers-reduced-motion` 全关 |

## 3. 功能清单（按模块）

### KPI 卡
- 抬头一行：`2026-11-30 · 日盘 · 14:36:01`，右侧 `15m TR 8852.5 / 8819.5`。
- 四格：距收盘（真倒计时，秒级）、当日已实现、持仓浮动（含现价）、日亏剩余（上限 ¥1,200）。
- 倒计时 15:00 归零；14:45 后副行转「已禁开新仓」。

### 01 失误清单
- 累计口径：历史交易日 + 今天所有交易里的错误码相加。
- 条数 = `×n`；今天犯过的挂「今天 n」小标签；按累计次数降序，同次数看今天次数。
- 抬头右侧：`累计 11 次 · 今天 3 次 · 5 类`；空态「今天还没有记录失误——保持住」。
- 抬头齿轮打开错误库弹窗。

### 02 风险闸门
- 结论在前（结论字 + 一句话理由 + 持仓信息），5 项检查在后。
- 检查项：时段允许开新仓 / 当日亏损未触及上限 / 连续止损少于 3 笔 / 连续盈利少于 4 笔 / 无持仓、无挂单。
- 通过显绿、拦截显红，拦截项整行加深。

### 03 盘中走势
- 标题右侧：合约下拉（6 个品种）、`ATR14 · EMA20`。
- 工具条：3m/15m 切换、夜盘区间、`N 根 · 更新 HH:MM`。
- 手写 SVG：蜡烛 + EMA20 + 昨结虚线 + 夜盘底色 + 入场① / 出场② 编号徽标 + 止损/目标虚线。
- 不轮询：打开时按缓存补拉，时段结束后再拉一次。

### 04 交易记录
- 筛选：日期 / 形态 / 品种 / 关键词（匹配日期、时间、形态、备注、品种、方向），140ms 防抖；重置。
- 分页：每页 10 条（`PAGE_SIZE`），底部合计当前筛选的净盈亏、已平笔数、胜率。
- 列：日期 时间 方向 形态 品种 入场 手数 状态 错 盈亏 备注；窄屏只留 6 列。
- 标题右侧「＋ 添加交易」开弹窗。

### 弹窗
- **添加交易**：合约（可改，等于切上下文）、方向、入场/止损/目标、手数、入场时间、形态（只能选）、犯错（多选 chips）、备注、交易截图（点击或 ⌘V 粘贴）、风险实时联动；底部是「截图草稿」——解析结果与补齐止损/确认入账/丢弃。
- **形态库 / 错误库**：增删字典、显示各自使用次数；删掉不影响历史记录里的旧写法；Esc / 遮罩 / × 关闭。
- 保存后弹窗关闭，新行高亮并滚入视野。

### ⌘K 全局搜索
- 四类：动作（去各模块 / 切明暗 / 切涨跌 / 添加交易 / 开字典）、交易、手册规则、品种。
- ↑↓ 选择、↵ 打开、esc 逐层退出；规则可钻取全文；选交易自动翻到对应页并高亮；选模块滚动并脉冲。

## 4. 这一版修掉的坑（都值得记住）

1. 保存处理器硬编码 `size:6` 覆盖分页 → 抽出 `PAGE_SIZE` 常量。
2. 删除按钮属性不一致：形态库 `data-del`、错误库 `data-del-err`。
3. 空值样式与 `.errs` 同权重 → 空值改用独立的 `.dim` 元素。
4. `#fErr` 的 change 里先 `value=""` 再取值，否则重复选同一项不触发。
5. 布局用 12 栅格会在矮的一侧留几百像素空洞 → 改纵向 flex 栈。
6. `.row-two #m-gate{flex:0 0 452px}` 在窄屏没重置 → 移动端闸门被撑到 452px。
7. 粘性顶栏会盖住 ⌘K 跳转的模块标题 → `.mod{scroll-margin-top:72px}`。
8. `file://` 下只改 hash 不会重载文档，旧 CSS 会残留 → 验证时加 `?v=` 查询串。
9. 删除元素后忘了删对应 `getElementById().textContent = …`，整页脚本中断、列表空白。
10. 切品种时 `rebuild()` 会覆盖整个 `trades` 数组 → 先筛出用户手动加的记录再拼回。

## 8. 样张配色皮肤（2026-11-28 晚）

此前插件全部取 `--dsw-alias-*`，与样张写死的调色板在明暗两套下都对不上。v13 把样张配色内嵌为插件皮肤，DSH token 只作兜底。

### 调色板

| 变量 | 浅色 | 深色 |
| --- | --- | --- |
| `--tc-paper` | `#fafaf8` | `#171717` |
| `--tc-paper-2` | `#f2f2f0` | `#1f1f1e` |
| `--tc-ground` | `#f0f0ee` | `#0e0e0d` |
| `--tc-ink` | `#0a0a0a` | `#f2f2f0` |
| `--tc-t2` | `#525252` | `#b0b0ad` |
| `--tc-t3` | `#767674` | `#8a8a87` |
| `--tc-line` | `#d4d4d2` | `#3a3a38` |
| `--tc-line-2` | `#e2e2e0` | `#2a2a28` |
| `--tc-accent` | `#002fa7` | `#7d9bff` |
| `--tc-green` | `#147a4a` | `#3fbf7f` |
| `--tc-red` | `#b42318` | `#ff6b5e` |
| `--tc-warn` | `#8a5a00` | `#d5a13a` |

### 实现

- `.tc-root[data-scheme]` 把上面 12 个变量映射到 `--dsw-alias-bg-base / layer-1 / layer-2 / bg-overlay / border-l1 / border-l2 / label-primary / label-secondary / brand-primary / state-success / state-error / state-warn`。原有全部 `var(--dsw-alias-*)`（含 SVG K 线、弹窗、按钮、规则/决策两栏）自动落到样张色。
- `detectScheme()` 先读宿主 `--dsw-alias-bg-base` 的亮度（<0.45 深色），再查 `html/body` 的 class / `data-theme` / `data-scheme`，最后回退 `prefers-color-scheme`；`MutationObserver` 监听主题切换。
- 找不到宿主颜色时，`data-scheme` 缺失，别名不被覆盖，继续用 DSH token 兜底。
- `[data-palette="cn"]` 只交换 `--tc-up/--tc-down`；K 线、开平标记、涨跌数字跟随，状态色（通过/拦截）不翻。

### 验证

- `node --check client.js lib/index.js` 通过；`node --test test/core.test.js` 15/15。
- jsdom 下 `data-theme=dark → light`，`.tc-root[data-scheme]` 随之切换。
- 真实 GUI（临时鉴权 URL）：深色 `backgroundColor: rgb(14, 14, 13)`、面板 `#171717`、强调色 `#7d9bff`；模拟浅色宿主后 `rgb(240, 240, 238)`、面板 `#fafaf8`、强调色 `#002fa7`，与样张一致。
- 临时鉴权代码与 `/tmp/dsh-trading-cockpit-url.txt` 已删除并 reload。
