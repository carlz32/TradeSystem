# 交易中控台 · 视觉样张

`index.html` 是静态样张：直接双击用浏览器打开即可，不需要构建、不联网、不接真实行情（K 线和交易都是种子生成的示意数据）。

现在是**单页模块板**，没有 tab、没有二级页面。六个模块排在一张板上：

01 失误清单 ∥ 02 风险闸门（同一行，左宽右窄）
03 盘中走势（整幅全宽）
04 交易记录（整幅全宽，可翻页 / 筛选 / 搜索）

**添加交易不占模块**，点交易记录标题右边的「＋ 添加交易」弹出表单；粘贴或选择截图后，解析出的草稿就显示在表单底部（同一个弹窗里）。

形态库、错误库同样收进弹窗：失误清单头部的齿轮开错误库；形态库的入口在添加交易表单里「形态 / 状态」旁的「管理」。

顶部条只留品牌 / 搜索 / 涨跌配色 / 明暗；日期、时段、时钟和 15m TR 区间压进 KPI 卡的抬头一行；品种下拉在「03 盘中走势」标题右边，添加交易的表单里也能改。**同一信息只放一处**：距收盘只在 KPI 卡、14:45 只在它的副行、ATR/EMA 只在走势图标题、页码只在翻页器、乘数只在页脚。

## 交互（可以点）

| 位置 | 能做什么 |
| --- | --- |
| 右上「搜索」/ ⌘K（Ctrl+K） | 全局搜索：动作、交易、规则、品种四类。↑↓ 选择、↵ 打开、esc 关闭；选模块会滚到并打一圈高亮，选交易会翻到那一页并闪一下 |
| 交易记录 · 筛选 | 日期 / 形态 / 品种三个下拉 + 一个关键词框（匹配日期、时间、形态、备注、品种、方向），140ms 防抖；「重置」一键清空 |
| 交易记录 · 翻页 | 每页 10 条（`PAGE_SIZE`），`‹ 1 / 2 ›`；页脚汇总当前筛选结果的净盈亏、已平笔数、胜率 |
| KPI「距收盘」 | 真倒计时：每秒走，14:45 后转「已禁开新仓」 |
| 品种下拉（走势图标题 / 添加交易表单） | PP0 聚丙烯 / RM0 菜粕 / M0 豆粕 / V0 PVC / SR0 白糖 / SC0 原油；切换后 K 线、价格、手数乘数、风险额度全部按该品种重算 |
| 添加交易 · 形态 / 状态 | **只能从字典里选**，不能直接输入；点标签右边的「管理」弹形态库 |
| 交易记录 · 犯错 | 下拉多选（E1 入场太早 / E2 入场太晚 / E3 止损太紧 / E4 止盈不合理 / E5 逆势加仓 / E6 偏离计划 / E7 追单·情绪单 / E8 手数过大），选完变成可移除的小标签 |
| 概览 · 失误清单 | KPI 下面第一条：列**累计**犯过的错（历史交易日 + 今天），`×n` 是累计次数；今天犯过的挂一个「今天 n」小标签；交易记录一变就重算 |
| 失误清单 · 齿轮 | 弹出错误库：增删错误码（E1…），显示各自使用次数；删掉的码若还留在历史交易里，失误清单仍显示它并标「已从字典删除」 |
| 添加交易 · 表单里的「管理」 | 弹出形态 / 状态库：增删形态，显示被多少笔交易用过 |
| 弹窗 | Esc 关闭、点遮罩关闭、点右上 × 关闭；打开时焦点落在输入框 |
| 添加交易 · 交易截图 | 点虚线框选图，或在页面里直接 ⌘/Ctrl+V 粘贴剪贴板图片；解析结果出现在表单下方的「截图草稿」里 |
| 添加交易 · 保存 | 真的会往列表追加一行（含形态、错误码和缩略图），随后弹窗关闭并高亮新行；刷新即丢 |
| 右上「涨绿 / 涨红」 | 切换涨跌配色：绿涨红跌（国际惯例）↔ 红涨绿跌（国内习惯）。K 线、盈亏、方向小方块、图例一起换 |
| 右上「明暗」 | 切换亮/暗 |

## 设计语言

来自 [歸藏设计](https://github.com/guizang/guizang-design) 的瑞士/杂志风：0 圆角、1px 细线、等宽小标签、单一强调色、编号章节。

| 变量 | 值（明 / 暗） | 用途 |
| --- | --- | --- |
| `--ground` | `#f0f0ee` / `#0e0e0d` | 页面底 |
| `--paper` | `#fafaf8` / `#171717` | 卡片、面板 |
| `--paper-2` | `#f2f2f0` / `#1f1f1e` | 表头、选中行 |
| `--ink` | `#0a0a0a` / `#f2f2f0` | 主文字、主按钮底 |
| `--t-2` `--t-3` | `#525252` `#767674` | 次级 / 辅助文字 |
| `--line` `--line-2` | `#d4d4d2` `#e2e2e0` | 强调线 / 分隔线 |
| `--accent` | `#002fa7` / `#7d9bff` | 唯一强调色 |
| `--up` `--down` | `#147a4a` `#b42318` | 涨 / 跌、盈 / 亏 |

字号与间距：标题 12px 等宽（不再用大标题）、区块标题 15px/600、正文 13–15px、等宽标签 10–11px + `.1em` 字距、控件高 32–34px、区块间距 46px。

骨架：52px sticky 顶部条（品牌 + ⌘K + 涨跌配色 + 明暗，**没有 tab、没有品种和日期**）→ KPI 卡（抬头一行放日期 / 时段 / 时钟 / TR，下面四格数字）→ 模块板。

模块板是纵向 flex 三行：`.row-two`（失误清单 1fr ∥ 风险闸门 452px）→ K 线整幅 → 交易记录整幅。不要用 12 栅格拼，也不要把表单塞回板子里：表单进弹窗后，板上每块都是「数据展示」，宽度可以放心铺满。

≤1080px 时 `.row-two/.cols/.col-a/.col-b` 全部 `display:contents`，模块按 DOM 顺序自然排成单列（01→06），不需要 `order`。

## 移植到 client.js

1. `client.js:943` 的 CSS 常量只保留 `tc-*` 类名，取值换成宿主 token：`--ground → --dsw-alias-bg-base`、`--paper → bg-layer-1`、`--paper-2 → bg-layer-2`、`--ink → label-primary`、`--t-2 → label-secondary`、`--line/--line-2 → border-l1/border-l2`、`--accent → brand-primary`、`--up/--down → state-success-primary/state-error-primary`。
2. 删掉样张里的 `html[data-scheme]` 两套变量——宿主 token 本来就分亮暗，不要自己再存一份。
3. 圆角全部归零（现在 `.tc-card` 12px、`.tc-btn` 8px、`.tc-badge` 999px 都要改），阴影去掉，层次全靠 1px 线。
4. 统计区从「四张圆角小卡」改成一条外框内的四格，格间用 `border-left`；每格：10px 等宽标签 + 27px/300 数字 + 11.5px 说明。
5. 每个区块加 `01 / 02 / 03` 编号 + 下方 1px 实线，替换现在的 tab 下划线。
6. K 线继续手写 SVG（样张里的 `renderChart` 就是完整实现，约 120 行），不要引入图表库。
7. 顶部条 `position:sticky`；因为要跳到模块，`.mod` 必须给 `scroll-margin-top`（样张 72px），否则标题会被顶栏盖住。
7b. 两栏用 flex 栈 + `display:contents` 单列化，**不要用 CSS 栅格 + `align-items:start`**：模块高度差很大，栅格会在矮的一侧留几百像素空洞。
8. 倒计时用 `setInterval(tick, 1000)`，只重算时间相关文案（顶栏、闸门 01），不要整页重绘。
9. 形态 / 状态只能用 `<select>`（只读字典），**不要留自由输入**；增删只走设置页。
10. 截图走 `FileReader.readAsDataURL`，`document` 级 `paste` 在交易视图内生效；缩略图 24px 方框，点开再看大图。
11. 品种切换要整条链路一起算：锚点价 × K（K = 锚点 / BASE）、止损/目标距离、乘数、每手风险、日亏剩余。
12. 全局搜索在样张里是内存索引（动作 + `trades` + `RULES` + `SYMBOLS`），移植时换成真实数据源：执行手册分节、当日交易、品种表。选中规则看全文、选中交易跳到当日交易并高亮、选中品种直接切换，这三条行为要保留。
13. 快捷键用 `document` 级 keydown 监听 `(meta||ctrl) + k`。**先确认宿主没占用 ⌘K**：DSH 自己的命令面板如果也是 ⌘K，插件会被抢走，此时改成 ⌘⇧K 或只保留点击入口。弹层用 `position:fixed` + `z-index` 覆盖，不要塞进 slot 容器里（会被裁切）。
14. 形态 / 状态字典要落在 Host 侧（`notes/TradeLog/cockpit/` 下的 json 或插件设置），不能只放前端内存；交易记录里的下拉只读，设置页才允许增删。删项只从候选里去掉，**不要回溯改写历史交易**的 `pattern` 字段。
16. 失误清单的累计次数 = 历史 `cockpit/<交易日>.json` 里的 `errs` + 今天的交易，两边按码相加；「今天 n」就是今天那部分 > 0。**不要单独存计数器**，否则删改交易后计数会漂。
17. 涨跌配色做成两个别名 `--tc-up` / `--tc-down`：默认 `state-success-primary` / `state-error-primary`，切到「红涨绿跌」时互换。**状态色必须钉死别跟着翻**——「通过」永远是绿、「拦截」永远是红、「持仓」标签用中性色，不然红涨模式下整页会读反。偏好别改宿主 token，存插件自己的 localStorage / 设置项。

15. 列表分页在前端做（每页 10 条，`PAGE_SIZE`）；保存成功后要 `closeDlg()` 再高亮新行，否则提示留在已关闭的弹窗里看不见。真接过百条历史时，把筛选条件带到 Host 侧查询，别把整年数据塞进浏览器内存。

## 已知取舍

- **移动端 K 线**：SVG 等比缩放后轴文字太小，真机上应改成横向滚动或只留折线，样张没处理。
- 截图草稿、快捷键、表单校验都是静态示意，没有接线。
- 「保存」只写内存（`trades` 数组），刷新页面就回到种子数据。
- 品种只影响价格刻度和乘数，K 线仍是同一套种子形状。
- 涨跌配色不持久化，刷新回到默认绿涨红跌。
- 形态字典只在内存里，刷新恢复默认 8 项（错误库同理）。
- 弹窗没有做焦点陷阱（Tab 会跑出弹窗），真接插件时补一下。
- 搜索只做子串匹配，不支持拼音首字母和模糊匹配；规则正文命中时显示上下文摘要，但不做整页高亮。
- 规则查询、决策图两屏没做（⌘K 里能搜到规则，但没有独立的规则模块）。
- 历史交易是写死的 14 条（`HIST`），不是读文件；真接线时按 `cockpit/<交易日>.json` 逐日加载。
- 分页、筛选、搜索都在内存里做，没有接 Host 查询。
